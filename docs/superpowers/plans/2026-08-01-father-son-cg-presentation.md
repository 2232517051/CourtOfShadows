> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a matched empty-room/apparition CG pair to the hidden “父与子” ending, stage the father’s appearance and departure with lightweight Ren'Py effects, and protect the presentation with asset and render regressions.

**Architecture:** Treat the two WebP files as one presentation unit: the same first-person camera and room are cross-faded so only the father changes. Both images replace the stable Ren'Py alias `father_son_cg`, preserving one running ATL transform without affecting the protagonist portrait. Static Python tests own file format, dimensions, size budget, source ordering, gallery wiring, and audio anchors; a small Ren'Py test fixture proves the empty, manifested, and departed nodes load and render. The story label reuses the existing `grief.ogg` and `heartbeat.ogg`, so this batch adds no music, sound effect, or video asset.

**Tech Stack:** Ren'Py 8.5.2 script/test framework, Python 3 `unittest`, Pillow read-only image inspection, built-in `imagegen`, FFmpeg WebP conversion, PowerShell, existing CoS release scanners.

## Global Constraints

- Output exactly `game/images/cg_father_son_empty.webp` and `game/images/cg_father_son.webp` at 1280×720; their combined size must not exceed 1 MiB.
- Use the protagonist's first-person view across the desk; do not draw the protagonist into either CG.
- The father’s face must remain recognizable from `game/images/father.png`; change his clothing to a deep-blue robe and make only the body edges semi-transparent.
- Do not use horror imagery, unreadable text, signatures, watermarks, malformed hands, religious halos, or strong ghost particles.
- The empty and manifested frames must keep the same camera, desk, chair, lighting, and prop positions.
- Do not change the hidden-ending trigger, ending routing, dialogue, narration, or the nine persistent ending ids.
- Do not add MP4/video, original music, or external sound effects in this batch.
- Use existing `audio/music/grief.ogg` and `audio/sfx/heartbeat.ogg`; do not substitute UI sounds for wind or a door latch.
- Add `cg_father_son` to the CG gallery as `烛下告别`; do not add the empty frame as a separate gallery item.
- Every Ren'Py launch must use an explicit isolated `--savedir`; back up and compare persistent files around the run.
- The final handoff must include an asset-impact audit covering art, music, sound effects, animation, and package-size change.
