# “父与子”隐藏结局 CG 与演出设计

- **日期：** 2026-08-01
- **状态：** 已获用户口头确认，等待书面规格复核
- **所在分支：** `codex/v3-10-timeline-endings`

## 目标

“父与子”隐藏结局写明父亲坐在书桌对面、与主角交谈并逐渐消失，当前画面却始终使用夜间书房背景和主角立绘。此次补齐父亲显形、告别和空椅收束三个视觉节点，不改剧情文字、触发条件或结局判断。

## 已确认的取舍

- 构图采用主角第一视角。玩家隔着书桌看向父亲，画面不绘制主角，因此不会与普通／伤疤立绘状态冲突。
- 父亲的脸必须能认出，面部和胸口保持清楚，身体边缘半透明。
- 父亲不是恐怖幽灵：不用空洞眼睛、骷髅、烟雾触手、强烈冷光或宗教光环。
- 采用同机位双 CG，而非单张 CG 或透明父亲图层。双 CG 能让显形和消失使用稳定的交叉淡化，也避开头发、皮草透明抠图的不稳定边缘。
- 不制作 MP4。演出只使用 Ren'Py 转场、慢推近和轻微烛光亮度变化。

## 资产设计

### 输出文件

1. `game/images/cg_father_son_empty.webp`
   - 1280×720。
   - 主角视角，书桌横在前景，旧椅位于画面中部偏右。
   - 夜间石砌书房，单一暖色烛光，椅子无人。
   - 给左下角的主角对话立绘留出安全区。

2. `game/images/cg_father_son.webp`
   - 与空椅图的机位、书桌、椅子、灯光和物件位置一致。
   - 父亲坐在旧椅上，面孔沿用 `game/images/father.png` 的身份特征。
   - 服装改为深蓝色长袍；头发花白、面容较生前立绘清瘦。
   - 脸、眼睛和胸口清楚，肩臂以下逐渐融入暗处，轮廓半透明。

### 生成参考

- `game/images/father.png`：只作为脸部身份参考，不沿用红色皮草礼服。
- `game/images/bg_study_night.webp`：作为书房材质、夜色和烛光参考。
- `game/images/cg_end_truth.webp`：作为现有结局 CG 的写实程度、对比度和横版构图参考。

生成方式使用内置 `imagegen`。先生成父亲显形图并检查脸部、机位与安全区，再以该图为编辑目标移除父亲，得到严格匹配的空椅图。最终文件转为 1280×720 WebP；两张合计不超过 1 MiB，无文字、签名和水印。

## Ren'Py 接入

### 图片与画廊

- 在 `game/images_def.rpy` 定义 `cg_father_son_empty` 和 `cg_father_son`。
- 在 `game/gallery.rpy` 增加 `("cg_father_son", "烛下告别")`。
- 父亲第一次显形时调用 `unlock_gallery("cg_father_son")`；空椅图不单独占画廊项目。

### 场景顺序

1. `ending_father_son_epilogue` 开始时播放 `audio/music/grief.ogg`，淡入空椅 CG。
2. “然后——你看到了。”之后播放现有 `audio/sfx/heartbeat.ogg`，交叉淡入父亲显形 CG。
3. 对话期间保留现有主角立绘切换；父亲放在中部偏右，避免被左侧立绘遮住。
4. “他的身影越来越淡”之后，用较长交叉淡化回到空椅 CG。
5. “椅子是空的”至关门段落保持空椅画面，随后按原脚本淡黑。

### 轻量动画

在 `game/endings_expansion.rpy` 的隐藏结局附近新增一个局部使用的 ATL transform：

- 十八至二十秒内从 `zoom 1.0` 缓慢推至约 `1.025`。
- 通过幅度不超过 `0.025` 的亮度变化模拟烛火。
- 不移动父亲位置，不使用抖动、闪白或粒子特效。

## 音频

- 该段不再继承只有约 14.2 秒的 `ending_triumph.ogg`，改用现有约 96.6 秒的 `grief.ogg`。
- 父亲显形使用现有 `heartbeat.ogg`，不新增同类音效。
- 走廊风声和关门落锁声仍属于可选资产。本批不拿 UI 点击声冒充，也不引入来源或授权不明的外部音频。

## 失败处理

- 父亲脸部若无法与现有立绘对应，继续以 `father.png` 为参考迭代，不使用陌生面孔交付。
- 空椅图若改变机位、灯光或桌面物件，重新编辑，不把两张不匹配的图接进游戏。
- 生成图若出现多余手指、漂浮物件、不可读文字或水印，视为不合格。
- WebP 压缩后若超过体积上限，先调压缩质量；不降低 1280×720 的画面尺寸。

## 测试与验收

接入前先在 `Tools/test_story_timeline.py` 增加失败测试，覆盖：

- 两张资产存在，均为 1280×720 WebP，合计不超过 1 MiB。
- `images_def.rpy` 定义两张 CG，`gallery.rpy` 登记显形图。
- 隐藏结局从空椅开始，在“你看到了”后显形，在“身影越来越淡”后回到空椅。
- 该段切换到 `grief.ogg`，显形时播放 `heartbeat.ogg`。
- 没有为本段新增视频文件。

完成后运行：

- 新增的静态回归测试，确认 RED 后再实现并转为 GREEN。
- `python -m unittest discover -s Tools -p "test_*.py" -v`。
- 完整 Ren'Py testsuite 与 lint，使用隔离 `--savedir`。
- 画廊项目检查。
- 空椅、显形、消失后三个节点的 1280×720 实际渲染检查。
- 资产体积、缺图、缺音频和本次改动的新增资产需求复核。

Ren'Py 测试结束后再次核对玩家持久数据哈希；若测试同步改写工作树内的 `game/saves/persistent`，先备份测试写入物，再从已验证副本恢复。
