# 《权谋之庭》最小约束 Opus 文案生成设计

**日期：** 2026-08-05

**状态：** 对话设计已确认，待用户复核书面设计

## 一、目标

通过 Claude Code 调用 `claude-opus-4-6`，尽可能排除项目规则、技能、插件、历史会话和人为文风说明，让 Opus 依靠自身能力生成游戏文案。

Claude Code 自带的基础系统提示无法从 Claude Code 调用链中完全排除。本设计接受这一残余前提；若未来要求连该系统提示也不存在，必须另行改用 Anthropic Messages API。

## 二、调用方式

每次文案生成都使用全新、无持久化会话：

```powershell
claude --safe-mode --model claude-opus-4-6 --effort max --tools '' --no-session-persistence -p --output-format json "<用户原始要求>"
```

- `--safe-mode`：禁用 `CLAUDE.md`、技能、插件、Hook、MCP、输出风格和自动记忆。
- `--model claude-opus-4-6`：在实际生成调用中直接锁定模型，不依赖另一会话中的 `/model`。
- `--effort max`：不再沿用用户设置中的 `medium`。
- `--tools ''`：不允许模型自行读取项目或引入额外上下文。
- `--no-session-persistence`：不继承或保存生成会话。

## 三、输入边界

传给 Opus 的内容只包含用户当前的原始写作要求。必要时可以附上用户明确要求重写的原文，但不得附加：

- Codex 旧稿、落选稿或润色稿；
- 文风库、正例、失败原因或模仿对象；
- “必须、不得、不能”等禁写清单；
- 分支变量清单、测试契约或实现细节；
- Codex 对理想文风、节奏、措辞和结构的解释。

本次调用使用的最小任务文本为：

> 请重写《权谋之庭》本次更新涉及的文案：婚约退出与解释、英格丽家庭尾声、人民领主现实化。

## 四、输出与应用

1. 原样展示 Opus 返回的正文，不由 Codex 删改、拼接或润色。
2. 同时报告返回记录中的实际模型；`max` 由本次调用参数直接锁定并原样报告。
3. 在用户明确批准前，不把文本写入 `.rpy`。
4. 若文本存在 canon 或分支问题，Codex 只能在正文之外列出事实问题，不得擅自改写正文。
5. 用户批准后，任何为了 Ren'Py 语法或分支接入而必须改变的文字，都要再次单独确认。

## 五、非目标

- 不删除项目的代码测试、canon 扫描、立绘检查、发布门禁或资产检查。
- 不修改美术、音乐、音效、动画或 UI 资产。
- 不承诺消除 Claude 模型自身和 Claude Code 基础系统的内置安全行为。
- 不使用 `writing-game-copy`、`qu-ai-wei`、`webnovel-writer` 或项目原创文风库。

## 六、成功标准

- 返回记录确认模型为 `claude-opus-4-6`，调用命令明确包含 `--effort max`。
- 会话无工具、无持久化、无自定义提示来源。
- Opus 只收到上文列出的最小任务文本。
- 向用户展示的正文与 Opus 原始返回逐字一致。
