# v3.10 时间线与九结局测试设计

日期：2026-08-01

## 目标

本批次只解决两类已经确认的问题：

1. 终章在十天战争倒计时前仍会进入季度建设和丰收祭，导致一个月工程与三月初春的战局直接冲突。
2. 主谜案收束处存在时间、王历和证据称谓穿帮，同时开发者结局面板与快速测试仍只覆盖旧版五结局。

实现完成后，终章只保留已经存在的十日备战选择；真相线使用一条可自洽的五年尾声；结局工具以当前九个实际结局和难度配置为准。

## 不在本批次处理

- 第三章强制支线与主谜案节奏
- 属性选项的软检定扩展
- 安装包减包
- About、README、PV 与商店文案
- 北境外章入口
- 对现有结局正文做整体润色或重写

## 方案

### 一、终章移除季度内容，复用既有十日备战

`chapter5_start` 不再调用 `gov_building(5)`，也不再触发仅在终章调用的 `gov_festival`。两个 label 本身保留，不删除，以免影响从旧存档中途恢复。

第五章随后已有一组与十天倒计时直接相连的选择：

- 派出更多斥候
- 加固城防
- 疏散城外村庄

这三项都有即时成本、属性变化和后续文本回响，足以承担终章备战选择。第二、三章的学堂、诊所、粮仓、望楼建设完全不动；此前建成的设施仍能在第五章提供原有加成。

不把第五章的临时准备写回 `built_school`、`built_clinic`、`built_granary`、`built_watchtower`。这些变量表示已经建成的永久设施，误置位会让后文声称五千石粮仓或完整诊所早已投入使用。

### 二、收紧主谜案时间锚与证据称谓

只改已定位的穿帮句，不扩写场景：

- 第三章“第二天傍晚”改成不与“刺杀后第三天”争夺编号含义的相对时间锚。
- 王子取得的文件明确记录父亲近期那场官方所谓的“病故”，不再写成二十年前的事故。
- 终局展示的遗诏称为“原本”，与路线门槛 `testament_original_obtained` 一致。
- 先王遗诏写于王历二百七十三年；二十年后的终局旧王历应为二百九十三年。
- 真相结局重启王历后，扩展尾声统一为“五年后 / 新王历五年”。
- “父与子”隐藏尾声发生在上述五年尾声之内，所有表示父亲去世时长的“十年”统一为“五年”；父亲也不再声称自己错过了主角的童年，因为他直到主线开场前仍在世。普通往事不再额外制造新的年份锚。

实际改写前使用 `writing-game-copy` 指定的《杰里安王子》《布兰特爵士》中文语料作 Few-shot，只替换必要句子，不重写整段。

### 三、让开发者工具按九个实际结局工作

`balance.rpy` 的 `_ending_requirements` 扩展为当前九个持久化结局键：

- `iron_lord`
- `shadow_king`
- `holy_guardian`
- `peoples_lord`
- `truth`
- `borgia`
- `vassal`
- `fall`
- `sea`

`resist` 是通往 `iron_lord` 的终章路线，不是第十个结局。结局可达性层会把 `routes["iron_lord"]` 与 `routes["resist"]` 合并为同一个铁腕结局，避免玩家可以通过男爵联军进入铁腕结局时，调试面板仍显示铁腕不可达。

特殊结局分别显示缺失条件；四个主属性结局继续读取 `get_ending_threshold("primary")`，不再用测试数据中的固定 60 代替当前难度门槛。

### 四、测试策略

先写失败回归，再改正文和逻辑。

1. 新增轻量 Python 时间线回归测试，检查：
   - 第五章开场不再调用季度建设或丰收祭。
   - 四处旧穿帮文本不再出现。
   - 真相线使用二百九十三年、新王历五年和五年隐藏尾声。
2. Ren'Py 测试增加九结局目录一致性断言：`_ending_requirements` 必须与 `_ending_keys` 完全一致。
3. 用简单、普通、困难三个配置的实际门槛生成主结局样例；另测真相、毒药、附庸、陷落、南渡和“反抗归入铁腕”。
4. 补齐四个缺失的快速结局入口，并修正真相入口缺少遗诏原本的问题。
5. 运行：
   - 新增 Python 回归测试
   - 相关 Ren'Py testsuite
   - `python Tools/scan_ai_smell.py`
   - `python Tools/scan_canon.py`
   - `python scan_missing_portraits.py`
   - `python scan_narration_overlap.py`
   - Ren'Py lint

本批次不改 screen 文本插值和布局，因此不新增渲染截图门禁。

## 兼容性与风险

- 不删除治理 label，旧存档若正停在建设或丰收祭场景中仍能继续。
- 不改永久建设 flag，既有存档的设施与战争加成保持原样。
- 只调整显示时间与测试/调试映射，不迁移新的持久化数据。
- 快速结局入口用于开发验证，不改变玩家正式路线。
- 新测试使用结局配置和现有九结局键作为事实来源，避免下一次扩结局后再次出现“工具显示通过但只扫了旧目录”的假绿。
