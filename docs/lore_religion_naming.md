# 神称呼 Lore 对齐文档（权谋之庭 ↔ 铁与誓）

> 依据 2026-05-02 决定：CoS 的神称呼**不统一改为「永恒者」**（美术含十字架/圣母像，改称谓会与画面打架），改为用本文档固定各称谓的 lore 地位与使用规则。写新文本前查这里。

## 一、两作的教会是同一个教会

- 《权谋之庭》（前作，艾登堡时代）：教会通行称谓是「圣母」「上帝」。
- 《铁与誓》（续作，约一代人之后）：教义经过一次正典化，官方称谓统一为「永恒者」，圣人体系固定为「七圣徒」。
- **Lore 解释**：CoS 时代的信仰处于「正典化之前」——各地教会对同一位神有不同的惯用称谓。「上帝」是通称，「圣母」是民间与地方教会最常用的慈悲位格（对应后世永恒者信仰中的慈悲面向）。铁与誓时代的教会改革把这些称谓收拢进「永恒者」名下，圣母被追认为七圣徒源流的一部分。
- 这样两作文本都不用改：CoS 出现「圣母/上帝」= 时代正确；铁与誓出现「永恒者/七圣徒」= 改革后正确。

## 二、CoS 写作使用规则

| 称谓 | 谁用 / 什么场合 | 现存量 |
|---|---|---|
| **圣母** | 教会的正式场合与机构名（圣母教会、以圣母之名调停、修女祷词）；lily_master 等提及教会时也用 | ~47 处 |
| **上帝** | 个人化的信仰表达（主教忏悔、玩家/艾琳娜谈信不信、墓志式发问） | ~25 处 |
| **神明** | 怀疑论/哲学语境（主教信仰危机时刻意用的疏离词——"连神明都不确定是否在倾听"） | ~4 处 |
| 永恒者 | **CoS 里禁止出现**（正典化尚未发生） | 0 处，保持 |
| 七圣徒 | **CoS 里禁止出现**（同上）。七近卫≠七圣徒，别混 | 0 处，保持 |

### 判断口诀
- 说**机构/仪式/政治**（教会出面、调停、绝罚）→ 圣母。
- 说**个人内心**（信不信、忏悔、临终）→ 上帝。
- 说**怀疑与动摇**（主教的信仰危机线）→ 神明（这是主教的语声记号，别的角色少用）。

## 三、与铁与誓的接线（写续作内容时）

- 铁与誓文本可以让老一辈角色偶尔说漏「圣母保佑」再被年轻教士纠正为「永恒者」——这是免费的时代感，不算错误。
- 铁与誓的「暗百合异端」判定与 CoS 的暗百合组织同源（CoS 档案：暗百合=莲卫所创）。CoS 里教会与暗百合的敌对（影卫印记=教会之门关闭）是铁与誓异端认定的前史。
- 七近卫（剑/盾/幽/鹰/根/桥/莲）是**王室武官建制**，与教会七圣徒无关。两作都不要把这两个"七"接在一起。

## 四、遗留张力（已知，不修）

- CoS 个别场景「上帝/圣母」在同一场戏内混用（如主教线）——按上表属于"机构 vs 内心"的正常切换，不算矛盾，不要为统一而改。
- 美术素材（教堂 CG、十字架、圣母像）以圣母教会为准，与本文档一致。
