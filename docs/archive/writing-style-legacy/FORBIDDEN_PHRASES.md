# Court of Shadows — 禁用句式清单

写剧情 / 旁白 / 对话前看一遍。写完后用这个清单逐项扫。
完整版（含历史/原例）见 `memory/feedback_cos_no_ai_smell_dialogue.md`。

---

## 判定总则（2026-07-11 用户逐句终审定，优先级最高）

用户逐句终审序章开头 22 句，全部保留，包括多句「结构撞款」的：
"1325年的冬天，比任何人记忆中的都要冷"（烂俗开场腔）、"你不知道格雷伯爵是谁。你只知道他的儿子费利克斯很胖"（不知道X/只知道Y 结构）、"世界很大。大到你跑不到尽头"（顶针）。

**结论：句式结构撞款不构成修改理由。内容具体、贴人物视角、有信息量 → 保留。**
只修「内容本身是抽象格言 / 哲理 / 说教 / 升华」的句子。拿不准 → 保留。
下面 A-E 各类都在此总则之下适用：清单点名的是「格言腔」，不是「句形」。

## A. 句式层（最容易翻车）

### A1. 排比金句（3 段或以上同结构）
- ❌ "X 不是 Y。是 A。是 B。是 C。"
- ❌ "X 时候 A，Y 时候 B，Z 时候 C。"
- ✓ 减到 2 段，或改散文叙事

### A2. 反转金句（期望 vs 现实）
- ❌ "X 我丢了——其实没丢"
- ❌ "我以为 X，后来发现 Y"
- ❌ "X 也是 Y"
- ✓ "钥匙我自己藏起来了"

### A3. 比喻金句（"像 X" 抽象）
- ❌ "像一道泪痕" / "像树的年轮" / "像告别一个老朋友"
- ✓ 删比喻 / 改具体感官

### A4. 拟人金句（物品 + 心理动词）
- ❌ "瓶子也喜欢这样" / "它们也需要被忘记" / "它们自己也不喜欢被看太久"
- ✓ "我也懒得去想它"
- **例外**：核心设定的拟人保留（CoS 没有此类核心设定）

### A5. 顶针修辞（前末 = 后首）
- ❌ "一本写完了，开始写第二本。第二本写完了……"
- ✓ "写了两本之后，我就懒得再写了"

### A6. 普遍化金句（"X 就是这样"）
- ❌ "茶壶就是这样——用久了，都会裂一点"
- ✓ "茶壶用久了就这样。我也没在意"

### A7. 抽象升华收尾
- ❌ "那时候的我说的话，现在的我未必接得住"
- ❌ "挂着，就一直是一段没说完的话"
- ✓ "做了，我就再没有这两条鱼了。所以挂着"

### A8. "X 也 X" 重复对仗
- ❌ "扔了，就好像他们彻底走了 / 留着，这些东西替他们继续坐……"
- ✓ 留前半，砍后半

## B. 词汇层

### B1. 单字名词（星 / 月 / 风 / 雨 / 雪 / 火）
- ❌ "看星" / "王都的星少"
- ✓ "看星空" / "王都的夜空看不到几颗星星"

### B2. 抽象总结字（稳 / 实 / 远）
- ❌ "让发丝落得稳一点" / "金币比剑稳"
- ✓ "让发丝顺着颈线垂下来" / 直接删

### B3. 自创四字短语
- 自检：百度搜得到吗？搜不到 → 改口语
- ❌ "礼数留半" / "守心如月"
- ✓ "不必客套" / 删

### B4. 信念名词化 + 引号
- ❌ "那套 'X' 的规矩 / 原则 / 信条，我守不住了"
- ✓ "我从来没遇到过把我当人看的人"

### B5. 概念名词 + 抽象动词
- ❌ "做出抉择" / "面对真相" / "承担责任"
- ✓ "签了字" / "你只剩三秒"

### B6. 抽象空泛短语（设计文档也禁）
- ❌ "让 X 走多远" / "走得有多远"
- ❌ "感受到 X 的重量"
- ❌ "把玩家拉进 X"
- ❌ "真正的 X" / "真正 X 起来"
- ❌ "这才是 X 应该 X 的东西" / "这才是 X 的核心"
- ❌ "玩家一眼就能看到 — XX"

### B7. "X 很 Y，很 Z" 双形容词对仗
- ❌ "她的笑很慢，很深" / "她的眼神很冷，很远"
- ✓ "她抬起眼角" / "她停了几秒才收回手"

### B8. 抽象"躲"当回避道德责任
- ❌ "你没躲" / "你躲不开"
- ✓ "你没逃避" / "你没转身" / "你没装作没听见"

## C. AI 说教味（17 系列，玩家最容易识别）

### C1. 角色出戏发议论
- ❌ 角色任务讲完后说 "无论选择什么，重要的是 [价值观]"
- ✓ 角色只讲自己关心的、自己看得到的。价值观让玩家判断

### C2. 旁白评价"勇敢的选择"
- ❌ "这是一个 [勇敢/正确/艰难] 的决定"
- ✓ 旁白只描述后果（谁知道了 / 谁脸色变了 / 钱袋少了多少）

### C3. 反派话太"正确"
- ❌ 反派讲完邪恶计划后 "我理解你的反对，但请考虑 [中庸观点]"
- ✓ 反派从自己利益和愤怒出发，不要"看见两面"

### C4. 道德选项均匀化
- ❌ A/B/C 三个选项都不偏不倚 / 都很 reasonable
- ✓ 1-2 个明确带代价 / 让某 NPC 失望 / 牺牲一个具体利益

## D. 物理 / 美术 / 身份合理性

### D1. 物品描述脱离美术
- 写场景互动前对照美术资源
- ❌ "壁炉的粉色丝带"（实际是壁炉颜色不是丝带）
- ❌ "鸡蛋用一根线拴着挂起来"（鸡蛋会摔碎）

### D2. anonymous 角色的"身体取下一块"
- 原本针对人鱼/精灵的"鳞片/羽毛"描述，去掉身份后变成切自己肉
- ❌ "她从自己身上取了一小块下来"
- ✓ "她从自己披肩上剪下来一小块"（衣物/配饰替代身体部位）

---

## E. 主谓 / 语法

### E1. 主谓搭配错
- 写完一句**念出来**，问：主语是什么词性？谓语对主语成立吗？
- ❌ "辛辣冲鼻，流下来的至少不是哭"（"流下来的"=眼泪 名词，"哭"=动词，不通）
- ✓ "辣根冲鼻子，眼泪跟着掉。别人看着，像是被辣的"

## 写前自检（强制）

1. 这句话角色真的会这么讲吗？还是我在替角色写台词？
2. 这是具体动作/物件/感官，还是抽象总结？
3. 删掉这句，损失什么？

## 写后扫描清单（按字母对照）

| 项 | 检查内容 |
|---|---|
| A1-A8 | 排比 / 反转 / 比喻 / 拟人 / 顶针 / 普遍化 / 升华 / 重复对仗 |
| B1-B8 | 单字名词 / 抽象总结字 / 自创成语 / 信念引号 / 概念抽象动词 / 空泛短语 / 双形容词对仗 / 抽象"躲" |
| C1-C4 | 角色出戏说教 / 旁白评价 / 反派话太正确 / 选项均匀化 |
| D1-D2 | 物品脱离美术 / anonymous 身体取一块 |
| E1 | 念出来主谓搭配 |

每发现 1 处 → 改成 **具体动作 / 具体观察 / 具体物件**。

## 替代写法

- **砍掉对仗后半** → 让前半的具体动作站住
- **改成具体场景细节** → 把抽象金句删，让动作落地
- **留白** → 角色点头 / 沉默 / 转身走开，不必收尾金句
- **拆分顶针** → 改成两个独立陈述

## 不绝对禁

- 角色性格本就"爱说金句"的 NPC 可保留（CoS 艾琳娜偶尔讽刺式可以）
- 默认：**所有人都不该**这样写，例外要明确知道理由
