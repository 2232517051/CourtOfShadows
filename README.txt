权谋之庭 - Court of Shadows
=============================
Windows 版 v3.9.2

【运行游戏】

1. 解压整个压缩包，不要单独移动其中的文件。
2. 双击 CourtOfShadows.exe 启动游戏。

【游戏内容】

父亲骤逝后，你从王都返回故乡，继承艾登堡并成为新任领主。他留下的死因疑案尚未查清，贵族、教会与王权已经开始争夺这片领地的去向。

故事共五章，包含九个主线结局与一个隐藏尾声。你的选择会关闭一些道路，也会打开另一些道路；无法选择的选项，往往与先前的决定或当前状态有关。

【基本操作】

· 鼠标左键或 Enter：推进对话
· 鼠标右键或 Esc：打开游戏菜单
· Ctrl：快进已读文本
· 鼠标滚轮：查看对话记录

存档和设置会保存在本机。覆盖安装新版本前，请保留原有存档目录。
