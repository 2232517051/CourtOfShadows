权谋之庭 - Court of Shadows
=============================
中世纪宫廷权谋视觉小说

【安装步骤】

1. 下载 Ren'Py SDK：
   https://www.renpy.org/latest.html
   下载后解压即可，无需安装。

2. 将本项目文件夹 "CourtOfShadows" 移动到 Ren'Py SDK 目录下。
   例如：renpy-8.x.x/CourtOfShadows/

3. 打开 Ren'Py 启动器（renpy.exe），左侧项目列表中会出现 "CourtOfShadows"。

4. 点击 "启动项目" 即可运行。

【项目结构】

CourtOfShadows/
├── game/
│   ├── script.rpy        # 主剧本（第一章：新主登基）
│   ├── characters.rpy    # 角色定义与数值系统
│   ├── options.rpy       # 游戏配置
│   ├── gui.rpy           # 界面风格设置
│   ├── screens_custom.rpy # 自定义状态面板
│   └── images/           # 图片资源目录（待添加）
└── README.txt
